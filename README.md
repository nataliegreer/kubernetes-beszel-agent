# Kubernetes Beszel-Agent
## A [Kubernetes YAML file](https://github.com/nataliegreer/kubernetes-beszel-agent/blob/main/beszel-agent.yaml) that deploys beszel-agent as a daemon-set with automatic naming.

## Universal Token
- Access the universal token by going to the Beszel Hub settings, Tokens & Fingerprints
  - Set the persistence to "Permanent"
## Enviornment Variables
- The "KEY" enviornment variable can be accessed by clicking "Add System" on the Beszel Hub
- Set the "HUB_URL" enviornment variable to the location of the Beszel Hub
